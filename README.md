# Kobo 99 元書單行事曆 (ICS)

自動爬取 KOBO 部落格「一週99元書單」文章、解析書單並輸出可訂閱的 `.ics` (iCalendar) 檔案，供 Google 日曆「從網址新增」訂閱。
訂閱資訊：[複製網址](https://oshukezu.github.io/KOBO99-ics/public/kobo99.ics)
## 說明
系統每週四上午 08:17 開始，到下週三晚上 23:47 為止（台北時間），每小時的 17 分與 47 分會自動檢查一次最新選書資料。
網站首頁會自動產生 Google Calendar 訂閱連結，方便使用者追蹤選書資訊。所有選書紀錄都會儲存在 public/events.json，每次更新時，系統只會將新取得的資料與原有紀錄合併，不會刪除過去的歷史資料，確保每週更新後仍能保留完整紀錄。

### 文章尚未公布
週四 08:00 之後，若這一週的部落格文章明確回 HTTP 404，會先看 [Kobo 首頁](https://www.kobo.com/tw/zh) 的「今日 99」區塊，把當天這一本寫進行事曆與網站。首頁隔天換下一本，所以已抓到的日子會留著，例如週四的書留到週五再補週五那本。

首頁沒有這個區塊時，才在該週週四放上「目前尚未公布資料，請耐心等候」。部落格文章公布後，改成週四到下週三的整週書單，並移除這些首頁暫存與佔位。下週還沒到公布時間的 404 不會觸發。403、逾時或程式錯誤不新增佔位，也不刪掉已經抓到的暫存。下週三 23:47 那班仍沒有文章就停止高頻率檢查，下一輪仍會重試最近幾週。訂閱日曆（尤其是 Google 日曆）仍可能晚數小時才看到更新。

## 如何新增日曆
- 開啟 [Google 日曆](https://calendar.google.com/)
- 點選右上角 齒輪 > 設定
- 左側 一般 > 新增日曆 > [加入日曆網址](https://oshukezu.github.io/KOBO99-ics/public/kobo99.ics)
